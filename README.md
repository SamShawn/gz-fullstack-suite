# GZ Fullstack Suite

基于 Monorepo 架构的企业级全栈解决方案，包含：
- **web-bigdata**: 政企数据可视化大屏 (React + Vite + ECharts)
- **web-ai-ticket**: AI 智能工单协同系统 (Next.js)
- **server-core**: 核心业务后端 (NestJS + Prisma + PostgreSQL)
- **server-data**: 数据模拟微服务 (FastAPI + Redis)

## 快速启动
```bash
pnpm install
docker compose up -d
pnpm dev
```
